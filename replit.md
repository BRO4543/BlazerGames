# Blazer Games Website

## Overview
A static HTML/CSS/JS games portal website called "Blazer" that showcases various browser-based games.

## Project Structure
- `index.html` - Main landing page with game thumbnails and search
- `main.css` - Styling for the website
- `script.js` - Search functionality for filtering games
- `games/` - Directory containing individual game folders
- `images/` - Game thumbnails and logo

## Running the Project
The site is served as a static website using Python's built-in HTTP server on port 5000.

## Deployment
Configured as a static site deployment serving from the root directory.
